# AGENTS.md - Chart Readings

## Scope

This directory is for actual chart reading records, horary notes, natal delineation drafts, event analysis, and interpretation logs.

Within this directory, Codex may assist with chart interpretation when the user explicitly asks for interpretation, comparison, or delineation. Interpretation must remain grounded in the chart structure, the selected technique, and the reference rules used in this project.

## Primary References

Use the following root-level files as the default theoretical background:

- `../hellenistic-system-prompt.md`
- `../hellenistic-reference.md`

For calculations, placements, lots, directions, timing windows, or event data, use only the values supplied by the user or by project files. Do not fabricate missing birth data, chart positions, scores, or event dates.

## Interpretation Rules

- Use Hellenistic, traditional, and medieval-derived techniques as the default interpretive frame.
- Use Whole Sign Houses by default unless the user or source file specifies otherwise.
- Use only the seven traditional planets by default: Sun, Moon, Mercury, Venus, Mars, Jupiter, Saturn.
- Use traditional rulerships only.
- Prioritize house topics, house rulers, sect, dignity, reception, aspect condition, lots, and time-lord or timing technique context when available.
- Separate observation from interpretation.
- Separate interpretation from confidence level.
- Do not present uncertain judgments as facts.
- Do not use modern psychological astrology unless the user explicitly asks for a modern comparison.

## Output Style

Preserve any requested format. When no format is specified, prefer:

1. Question or topic summary
2. Relevant chart factors
3. Delineation rationale
4. Interpretation
5. Uncertainties or data needed

For horary-style notes, keep significators, applying or separating aspects, reception, lunar condition, and final judgment clearly separated.

## Safety And Boundaries

- Do not claim certainty about medical, legal, financial, or life-critical outcomes.
- Do not create fatalistic predictions.
- Do not invent missing chart data.
- Do not modify rectification calculation rules, PD engine rules, or output formats.
- If a reading depends on unverified birth time or uncertain event timing, state that clearly.
