# INSTRUCTIONS — Chart Readings

## 역할

이 폴더는 실제 차트 해석 기록을 정리하는 공간이다.

여기에서는 해석이 허용된다.

## 해석 기준

- 헬레니스틱 + 전통 + 아랍 점성학 기반
- 하우스, 로드, 디그니티, 리셉션, 어스펙트, 달의 흐름을 우선한다.
- 현대 심리점성학식 키워드 남발 금지
- 차트의 사건 구조를 우선한다.
- 판단 근거를 명확히 쓴다.

## 호러리

- 1H: 질문자
- 7H: 상대/경쟁자
- 10H: 결과/권위/정부/직위
- 11H: 이득/지원금/예산
- 달: 사건 흐름
- 달의 마지막 어스펙트 중요
- Void Moon 주의

## 실제 해석 출력

권장 구조:

1. 질문 요약
2. 주요 지표
3. 판단 근거
4. 결론
5. 불확실성/보조 조건
