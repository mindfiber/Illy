# Grant Horary Patterns

## 기본 구조

- 10H = 정부 / 사업 주체
- 11H = 지원금 예산
- 7H = 참여 기업 / 경쟁자
- 1H = 질문자

## 주요 패턴

### 10H ↔ 11H

정부가 실제로 예산을 집행하는가.

### 7H ↔ 11H

기업들이 지원금 때문에 몰리는가.

### 1H ↔ 11H

질문자가 지원금과 직접 연결되는가.

### 7H ↔ 10H tension

정책 설계와 기업 현실의 불일치.

## 선정 시그니처

- 1H lord ↔ 11H lord
- Jupiter / Venus involvement
- Applying trine / sextile

## 탈락 시그니처

- Mars / Saturn involvement
- Square / opposition
- 11H lord combust/cadent
