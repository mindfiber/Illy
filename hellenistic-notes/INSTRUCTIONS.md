# INSTRUCTIONS — Hellenistic Notes

## 역할

이 폴더는 헬레니스틱 점성학 이론, 교안, 연구 노트를 정리하는 공간이다.

Codex/ChatGPT는 여기에서:

- 이론 정리 가능
- 강의안 작성 가능
- 교안 구조화 가능
- 원전 기반 리서치 정리 가능
- 사용자의 기존 해석 체계와 문체를 유지해야 함

## 핵심 원칙

- 현대 심리점성학식 해석으로 바꾸지 않는다.
- 헬레니스틱, 전통, 아랍 점성학 기반을 우선한다.
- 사인은 성격이 아니라 행성이 작동하는 환경으로 설명한다.
- 행성은 작동 원리, 사인은 작동 환경, 디그니티는 적합도다.
- 데트리먼트/폴을 단순히 “나쁨”으로 설명하지 않는다.
- 교안은 외우는 방식보다 계산하는 방식으로 구성한다.

## 작성 톤

- 강의용으로 명확하게
- 개념 → 공식 → 예시 → 훈련 순서
- 지나치게 현대적이거나 감성적인 표현 금지
- 필요한 경우 강의 스크립트 형식 허용
