# Codex Start Prompt

이 프로젝트는 ChatGPT에서 이어오던 Astrology 프로젝트다.

먼저 루트 `AGENTS.md`를 읽고, 작업 대상 폴더의 지침 파일을 추가로 읽어라.

- 생시보정 계산/엔진 작업이면 `rectification-tool/AGENTS.md`
- 헬레니스틱 교안/이론 정리면 `hellenistic-notes/INSTRUCTIONS.md`
- 실제 차트 해석이면 `chart-readings/INSTRUCTIONS.md`

하위 폴더별 규칙을 섞지 말고, 현재 작업 위치의 규칙을 우선 적용하라.
