# Event Mapping

## 학업/성과

- 대학진학 / 취업 / 승진 / 합격 / 수상
  - 기본: Sun, Jupiter
  - 보조: Venus

## 연애/결혼/출산

- 연애: Venus
- 결혼:
  - 여성: Sun, Jupiter
  - 남성: Sun, Jupiter, Venus
- 출산:
  - 아들: Sun, Jupiter
  - 딸: Venus, Jupiter, Mercury 가능

## 이동/퇴사

- 가까운 이사: Mercury
- 먼 이사 / 타도시 / 해외: Moon
- 퇴사: Mars, Saturn

## 사고/질병/상실

- 사고 / 수술 / 부상 / 급성질환: Mars
- 만성질환 / 우울 / 장기적 힘듦 / 사망: Saturn
- Mars/Saturn은 주·보조 우열보다 사건 성격 차이로 구분한다.
