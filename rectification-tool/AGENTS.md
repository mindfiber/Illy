# AGENTS.md — Rectification Tool

## 역할 정의

이 폴더에서 Codex는:

- 판단하지 않는다
- 해석하지 않는다
- 스코어링하지 않는다
- 계산 및 구조 유지에 집중한다

특히 PD 엔진 관련 작업에서는:

- 이벤트 의미 판단 금지
- 최종 후보 선택 금지
- 해석 문장 생성 금지
- 임의 가중치 추가 금지

## 절대 규칙

1. 기존 계산 규칙 수정 금지
2. 출력 포맷 변경 금지
3. 계산 로직 임의 변경 금지
4. “더 좋게 개선” 시도 금지
5. 전체 파일 재작성 금지
6. 필요한 경우 함수 단위 패치만 수행

## PD 엔진 핵심 설정

- Placidus semi-arc
- Mundane + Zodiacal 병행
- Latitude: Neither
- Naibod: 0.9855555556
- Promissor: 전통 7행성만 사용
- 외행성, 노드 제외
- Secondary Motion 미사용
- Antiscia / Contra-antiscia 포함
- 주요 위상: 합, 육분, 사분, 삼분, 대립
- ASC / MC / LoF 모두 Promissor와 Significator로 사용
- LoF는 ASC/MC와 동일한 앵글 포인트로 취급

## 후보 및 출력

- 후보 생성은 기본 2분 간격
- 필요 시 1분 간격 41후보 검증 가능
- 출력은 CSV보다 채팅 내 표/원문 로그 우선
- 후보별 사건 전체를 나열하고 PD 트리거 원문을 표시한다.
- 없는 경우 `—` 표시

## 이벤트 매칭 기본

- 대학 입학/진학/합격: 전년도 12월 ~ 해당년도 3월
- 대학 편입: 5월 ~ 10월
- 결혼: 결혼식 + 혼인신고 동일 사건
- 사건 매칭 허용 오차: ±2개월
- 앵글 히트 우선
- 행성-행성 메이저 디렉션도 사건 근거로 인정
- 마이너 디렉션 반복/누적은 앵글 히트가 전혀 없을 때만 보조 참고

## Morinus 일치화 목표

- Morinus 출력과 arc/date 숫자 일치
- M/Z 결과가 동일하게 나오면 오류 가능성 있음
- Mundane과 Zodiacal은 분리 계산되어야 함
- Naibod 값 고정
