# Rectification Tool Immutable Rules

이 파일은 생시보정 툴 작업의 불변 목적과 출력 규칙을 고정한다.

## Project Goal

이 프로젝트의 목표는 Morinus와 동등하게 동작하는 자체 생시보정 PD 엔진을 만드는 것이다.

Morinus PD 리스트는 최종 결과를 대신 산출하기 위한 입력값이 아니다. Morinus PD 리스트는 자체 PD 엔진의 오류를 검증하고, 계산 규칙을 고도화하기 위한 기준 자료다.

최종 목표는 사용자가 Morinus PD를 수동으로 뽑아 제공하지 않아도, 자체 엔진만으로 PD 생성, 사건 매칭, 생시 후보 산출이 가능해지는 것이다.

## Required Output Format

사용자가 결과를 가져오라고 요청하면, 반드시 다음 형식으로 출력한다.

1. 최종 생시 후보 1순위
2. 최종 생시 후보 2순위
3. 최종 생시 후보 3순위

각 후보에는 반드시 다음을 포함한다.

- 엔진 규칙의 중요도와 우선순위를 반영한 순위 근거
- 매칭 결과
- 해당 후보의 매칭 PD 리스트
- 해당 후보의 미싱 이벤트/미싱 PD 리스트
- 필수 이벤트 미싱 여부와 어떤 이벤트가 미싱인지

## Morinus Fixture Rule

Morinus 파일이 제공되어도 최종 후보 순위는 자체 엔진 결과로 산출한다.

Morinus 파일은 다음 용도로만 사용한다.

- 자체 엔진이 생성한 PD가 Morinus 원본과 같은지 검증
- 엔진 과생성/누락/날짜 오차를 찾기
- 계산식과 필터 규칙을 수정하기

Morinus 원본 PD를 직접 매칭하여 최종 후보 순위를 내는 방식은 이 프로젝트 목적에 맞지 않는다.

## Mandatory Events

결혼, 출산, 대학입학, 대학원진학, 첫 취업 등 필수 이벤트는 후보 판정의 최우선 기준이다.

필수 이벤트가 미싱인 후보는 본순위가 아니라 번외 검증 후보로 표시한다. 단, 연속된 마이너 또는 흐름형 브래킷으로 설명 가능한 경우는 예외 표시와 함께 수기 검증 대상으로 분리한다.
